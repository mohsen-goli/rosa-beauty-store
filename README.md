# ROSA — Beauty & Skincare Store

A modern, responsive beauty and skincare e-commerce frontend built with React, TypeScript, and Vite.

## Features

- Browse beauty and skincare products by category
- Product detail pages and related product recommendations
- Shopping cart with quantity controls
- Wishlist with localStorage persistence
- Live product search
- Category sorting by price and rating
- Checkout form with validation and a success page
- Toast notifications
- Responsive layouts for desktop, tablet, and mobile
- UI animations and loading skeletons
- Client-side routing and a custom 404 page

## Tech Stack

- React 19
- TypeScript
- Vite
- React Router
- React Context API
- CSS3
- Framer Motion
- Lucide React
- ESLint

## Getting Started

### Requirements

- Node.js
- npm

### Installation

```bash
npm install
npm run dev
```

Vite will display the local development URL in your terminal.

## Quality Checks

Run the following commands before submitting changes or deploying:

```bash
npm run lint
npm run typecheck
npm run build
```

## Project Status

This project is under development. Features that depend on a real backend or payment provider should be considered incomplete until they have been integrated and tested.
